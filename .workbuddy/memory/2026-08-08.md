# 2026-08-08 每日习惯打卡小程序 - 需求对齐

## 已确认决策
- 定位：个人 + 家人朋友使用（多用户，各自数据隔离、互不可见）
- 存储：微信云开发 CloudBase（免服务器/备案，openid 天然隔离多用户）
- 习惯管理：自由增删，自定义名称/图标/目标频次
- 目标频次：支持「每天一次」与「每周 N 次」两种
- 提醒：微信订阅消息（一次性订阅），用户打卡/打开时顺带请求授权
- 连续统计：同时展示「连续打卡天数」与「连续达标周数」双指标

## 技术架构（定稿）
- 页面：今天首页 / 习惯管理（增删改）/ 我的·历史
- 数据表：habits（习惯）、checkins（打卡记录，按天）
- 云函数：登录(openid)、打卡写入、连续统计、订阅消息定时推送
- 订阅流：打卡 → requestSubscribeMessage 授权 → 云函数定时触发器推送提醒

## 首批种子数据（采用建议集，首次打开预置）
- 健康：喝水2000ml(每天)、运动30分钟(每周4)、23点前睡(每天)、冥想10分钟(每天)
- 成长：读书20分钟(每天)、学英语(每周3)、写日记(每天)
- 生活：记账(每天)、整理房间(每周2)、给爸妈打电话(每周1)

## 开工前前置条件（需用户配合）
- 注册个人小程序账号，获取 AppID
- 开通云开发环境
- 申请订阅消息模板（一次性订阅，关键词：习惯名称/提醒时间）
- 配置用户隐私指引（用到 openid）
