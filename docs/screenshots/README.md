# 界面截图存放目录

把小程序界面截图放进这个目录，文件名按下面的顺序，README 顶部会自动按此顺序并排展示。

| 文件名 | 页面 | 入口 |
| --- | --- | --- |
| `01-today.png` | 今天（首页聚合） | 底部导航「今天」 |
| `02-features.png` | 功能（模块九宫格） | 底部导航「功能」 |
| `03-training.png` | 训练规划（日历排课） | 功能 → 训练规划 |
| `04-bill.png` | 记账（月度汇总） | 功能 → 记账 |
| `05-food.png` | 食物热量（AI 识别结果） | 功能 → 食物热量 |

拍摄要求：

- 机型统一选一个竖屏 iPhone，缩放保持 100%，五张图尺寸才会一致
- 只截模拟器画面，不要把工具栏和代码编辑器截进去
- 宽度控制在 800–1200 像素

> 建议直接用微信开发者工具模拟器面板上的「截图」按钮，它会把模拟器画面直接存成图片，省去手工裁剪。
